# Clientes del taller

App web sencilla para llevar el registro de los clientes de un taller mecánico.

## Funciones

- Alta, edición y eliminación de clientes (nombre, teléfono, correo, dirección, notas).
- Vehículos por cliente (placa, marca, modelo, año, color, kilometraje).
- Historial de servicios y reparaciones con fecha, vehículo, costo y estado
  (Pendiente, En proceso, Terminado, Entregado).
- Búsqueda por nombre, teléfono, correo, placa, marca o modelo.
- Resumen: total de clientes, vehículos y trabajos abiertos.
- Botones para llamar o escribir por WhatsApp al cliente.
- Exportar e importar los datos en un archivo JSON (copia de seguridad).

## Uso

Abre `index.html` en el navegador (computadora o celular). No necesita instalación
ni servidor. Los datos se guardan en el propio navegador, así que conviene usar
**Exportar datos** de vez en cuando para tener una copia de seguridad.
